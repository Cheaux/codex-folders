# Changelog

## 0.1.1

- Updated shared-host references to Codex Command Extensions. Added official-directory draft ZIP packaging, listing metadata, icons, public data/license information and proposed review cases.

## 0.1.0

First public Codex release.

- Local folders and subfolders, one-folder chat membership, All chats home, multi-chat moves and undo.
- Keyboard browser with visible new-folder and new-chat actions.
- Shared project instructions, default new-chat directory, revisioned brief, scoped message search and source references.
- Fourteen MCP tools, chat-folders skill, and two manually trusted context hooks.
- Modular Codex Command Extensions provider for /folders, bare /resume, /resumedbg and Ctrl+X F; independent removal preserves other providers.
- Linux verification, automated backend/MCP/package/PTY checks, public documentation and built release archive.

macOS is untested; Windows terminal backend and Claude distribution are outside this release.
